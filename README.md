# QR Code Component

A Simple Static QR code card component built with HTML and CSS. This project features a centered card design with a QR code image and accompanying text.

## Preview

The component displays a white card with rounded corners containing:

- A QR code image with rounded borders
- A bold title
- Descriptive text below

## Features

- 🎨 Clean and modern UI
- 🔤 Google Fonts integration (Outfit font family)
- 💫 Subtle shadow effects
- ♿ Semantic HTML structure

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Outfit)

## Project Structure

```
project-root/
│
├── index.html          # Main HTML file
├── style.css           # Stylesheet
└── Image/
    └── qr-code.png     # QR code image
```

## Installation

1. Clone or download this repository
2. Ensure the QR code image is placed in the `Image` folder
3. Open `index.html` in your web browser

## Usage

Simply open the `index.html` file in any modern web browser to view the component.

## Design Specifications

### Colors

- **Background**: `hsl(212, 45%, 89%)` - Light blue
- **Card Background**: `hsl(0, 0%, 100%)` - White
- **Title Color**: `hsl(218, 44%, 22%)` - Dark blue
- **Text Color**: `hsl(216, 15%, 48%)` - Gray blue

### Typography

- **Font Family**: Outfit (Google Fonts)
- **Base Font Size**: 15px
- **Title Font Size**: 22px
- **Title Font Weight**: 700
- **Body Font Weight**: 400

### Layout

- **Card Width**: 320px
- **Card Padding**: 16px (sides and top), 36px (bottom)
- **Border Radius**: 12px
- **Box Shadow**: Subtle shadow for depth

## Customization

You can easily customize the component by modifying the CSS variables in `style.css`:

- Change colors by updating the HSL values
- Adjust card dimensions by modifying the width and padding
- Modify border radius for different corner styles
- Update font sizes for different text emphasis

## Browser Support

This component works on all modern browsers:

- Chrome

- Safari
